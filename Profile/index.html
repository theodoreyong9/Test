03 — Protocol

Value moves. No global state.

A global-state-free value transfer and accrual system: no chain everyone must agree on, no server that holds the truth. An agnostic JavaScript execution infrastructure for the mass adoption of asset tokenisation.

Transfer

Signed actions, not a ledger.

Value moves by actions each person signs. Whoever needs a balance replays the actions it concerns and gets the same answer as everyone else.

Contracts

Smart contracts as plain reducers.

A contract is a rule: a state and an event give the next state. Tokens, subscriptions, any agreement is written the same way and checked by whoever replays it.

JavaScript

One agnostic runtime.

Pure JavaScript, so the same contract runs on a phone, a computer, a browser, or inside an agent. No virtual machine of its own, no network to join first.

Tokenisation

Make assets liquid.

Tokenisation exists to make what is hard to sell easy to exchange. The legal layer stays outside the protocol, where law lives, and plugs in when a legislator is connected.

Accrual

Value that builds up.

Payments, access and rewards accrue to the people they belong to, verified by replaying the record rather than trusting a middleman.

Agent-centric

The agent is the node.

Each person's agent holds, checks and exchanges for them. Society is the sum of agents that agree on rules, not of platforms that own the data.
